# 短线叠加策略说明

页面「EMA7/21/56 策略」按币卡片与「短线操作信号」15m / 1h 阐述，都来自浏览器直连币安 K 线后本地计算（`public/ema-core.js`）。自有信号引擎（Top 250 打分）是另一套，见仓库根目录 README。

周期：每个品种算 **15m / 1h**（完整短线叠加），另拉 **4h / 1d** 仅算 MACD+KDJ 背景。覆盖 BTC / ETH / BNB / SOL / XAU。

---

## 1. EMA7 / 21 / 56（均线跟随）

**参数：** EMA7、EMA21、EMA56；MACD(12,26,9)；RSI6。止损 2%、止盈 4% 仅作参考。

**读图：**

- EMA56 是多空分界。7 和 21 都在 56 上方 = 多头排列；都在下方 = 空头排列。
- **上穿 56 / 下穿 56**：EMA7 穿过 EMA56。表里「最近穿越」只标记这件事，**不是开仓**。
- **过滤开仓（做多 / 做空）** 必须同时满足：
  - 最近一次穿越仍在回看窗口内（15m 约 16 根，1h 约 12 根）
  - 价格在 EMA56 正确一侧
  - MACD DIF 在 0 轴同向（多要 >0，空要 <0）
  - RSI6 不极端（多 <65，空 >30）；若 DIF 与 DEA 相对价差足够大，可跳过 RSI

Pine 里另有一组「仅上穿/下穿就 enter」的单，**看板没有把它当成激活开仓**。

## 2. AlphaTrend（ATR 通道过滤器）

**参数：** ATR 周期 14（SMA 真波幅）、倍数默认 **1.5**；体制过滤用 MFI≥50（有成交量时）。主线相对滞后 2 根（Shift2）判多空。

**读图：**

- 主线在 Shift2 **上方**（绿）→ 只允许做多
- 主线在 Shift2 **下方**（红）→ 只允许做空
- Potential BUY / SELL：主线与 Shift2 交叉，并经过 bars_since 过滤

**用法：** 方向开关，不单独当开仓理由。和 EMA 过滤同向才算「共振开仓」。

**注意：** ATR/RSI 用 SMA，不是 TradingView 常见 RMA，数值会略不同。前十几根预热不要用。加密默认倍数 1.5，比脚本里的 1.0 少抖。

## 3. 布林带状态（BB 20, 2）— 卡片「布林」+ 上/中/下轨

只描述状态，**不单独发开仓**。

### 带宽（开口 / 闭口）

相对近 20 根带宽分位，以及近 3～5 根变化：

| 显示 | 含义 | 一般怎么用 |
|------|------|------------|
| 突然闭口 / 闭口收窄 / 持续收口 | 波动被压住 | 蓄势，等开口方向，先不追 |
| 突然开口 / 开口扩大 | 波动刚拉开 | 顺势，不摸头、不抄底 |
| 宽度稳定（震荡） | 带宽几乎不变 | 上轨高抛、下轨低吸，回中轨 |

### 价格位置（%B）

`%B = (收盘 − 下轨) / (上轨 − 下轨)`

| 显示 | %B 大致区间 |
|------|-------------|
| 上轨外 | > 1.05 |
| 贴上轨 | ≥ 0.85 |
| 中上 | ≥ 0.60 |
| 中轨 | 0.40～0.60 |
| 中下 | > 0.15 |
| 贴下轨 | ≥ 0 |
| 下轨外 | < 0 |

连续 3 根贴上轨 = 沿上轨走（强趋势，不是「超买就空」）。

### 组合提示（代码里的 hint）

- 闭口 + 在中轨一带 → 闭口蓄势，等开口
- 闭口 + 摸上/下轨 → 假突破 / 假跌破风险
- 开口 + 沿上轨 → 顺势不摸头
- 开口 + 沿下轨 → 顺势不抄底
- 宽度稳定 + 上轨 → 震荡高抛等回中轨
- 宽度稳定 + 下轨 → 震荡低吸等回中轨

## 4. BOLL 中轴开仓 — 卡片「中轴」，并参与共振

独立短线触发，和「布林」带宽状态不是同一套。量能默认 **1.4×** 15 根均量（原先 2× 过严，多数时间只显示观望）。

**做多（当前 K 必须同时成立）：**

1. 收盘 **高于** BOLL 中轨  
2. EMA6 > EMA12  
3. 快线相对斜率 `(EMA6 − EMA6[5]) / 5 / close > 0.0009`（按价格归一，多币种可比较）  
4. 成交量 > 15 根均量 × **1.4**  
5. 阳线（收盘 > 开盘）

**做空：** 中轨下 + EMA6 < EMA12 + 斜率向下超阈值 + 放量阴线。

**平仓参考（看板只提示，不模拟持仓）：**

- 多：价格跌回中轨下方  
- 空：价格升回中轨上方  
- 止损 1.5%

脚本里算了 `atr_val / highest(atr, 15)`（ATR 收缩），**没有写进开仓条件**，故不作为触发。未开仓时会列出缺哪一条。

## 5. 怎么叠在一起

| 角色 | 策略 |
|------|------|
| 方向开关 | AlphaTrend（绿只允许多，红只允许空） |
| 过滤开仓 | EMA7 穿 56 + MACD 0 轴 + RSI6 |
| 波动环境 | 布林带宽 + %B 位置 |
| 短线触发 | BOLL 中轴（中轨 + EMA6/12 + 放量 K） |
| 独立进出 | MACD+KDJ（15m/1h 执行；4h 过滤；1d 环境） |

**共振开仓** = AlphaTrend 方向 ∩（EMA 过滤做多/做空 **或** 中轴触发），再乘布林带宽：

| 布林带宽 | 合成结果 |
|----------|----------|
| **突然开口 / 开口扩大** | 同向时升为 **开口共振做多/空**（当作新趋势启动的有利条件，顺势不摸头） |
| **突然闭口 / 闭口收窄** | 即使 EMA/AT/中轴同向也改成 **闭口暂缓**（新趋势多半还没开始，不追） |
| **宽度稳定** | 同向仍可提示，但标成 **震荡环境做多/空**（摆动，不是新趋势，宜轻仓） |

中轴叠进去之后：

| 情况 | 合成 |
|------|------|
| AT+EMA 已同向，中轴也同向 | 原标签加 **·中轴**（确认） |
| AT 同向、中轴触发，但 EMA 过滤未齐 | **中轴共振做多/空**（短线轻仓，止损 1.5%） |
| 中轴与 AT 反向 | **中轴分歧**，观望 |
| 闭口阶段中轴触发 | 仍是 **闭口暂缓**，不追 |

一边多一边空 → 分歧观望。  
只有上穿 56、MACD/RSI 没过 → 不算 EMA 开仓（中轴仍可单独触发共振）。  
开口但还差 EMA 过滤 → **开口·等EMA多/空**（若中轴已触发则升为中轴共振）。

## 6. MACD + KDJ Signal（独立进出 + 大周期背景）

**参数：** MACD(12,26,9)，柱 = (DIF−DEA)×2；KDJ(n=9, K/D smooth=3)，超买默认 80。  
EWM 对齐 pandas `ewm(..., adjust=False)`，**与**上方「EMA 过滤」里 SMA 种子 MACD **不是同一条线**。

**15m / 1h（执行）：**

| 信号 | 条件 | 含义 |
|------|------|------|
| 入场边沿 | `hist>0` 且 `DIF>DEA`，且上一根不成立 | Long Entry |
| 持有区 | 上述多头条件仍成立 | 未离场 |
| 离场边沿 | K、D、J 全 &gt; 80，且上一根不成立 | Long Exit（**不是**反手做空） |
| 超买区 | 三线仍在超买 | 等回落或已提示离场 |

**4h / 1d（背景，不当同等开仓）：**

| 周期 | 用法 |
|------|------|
| **4h** | 过滤：本周期入场 + 4h 多头 → **顺势入场**；4h 非多头 → **逆势试多**（降权） |
| **1d** | 环境文案（日线多头/非多头）；不驱动日内 Exit |

卡片「背景」一行显示 4h/1d 的多头、空头或超买；执行列里的 MACD+KDJ 已叠好顺势/逆势标签。
